# Destiny item progression indicators

Use these signals to compare items without retaining random perk rolls.

| Indicator                           | What it tells you                                                               | How to use it                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Power (`primaryStat.value`)         | The app's existing per-item power value.                                        | Keep as its own axis. In the live profile sample, most Tier 0 items returned 10 while new Tier 4/5 items returned 300–412, so compare legacy and tiered gear separately until the value semantics are normalized.                                                                                                              |
| Gear tier                           | Item progression with defined gameplay benefits.                                | Strongest general signal for new tiered gear. Compare within a slot/item family; lower-tier weapons may still win through perk synergy. [Bungie's gear-tier explanation](https://www.bungie.net/7/en/News/Article/dev_insights_weapon_gear_tier), [Update 9.7](https://www.bungie.net/7/en/News/Article/destiny_update_9_7_0). |
| Armor stat total                    | Total of Mobility, Resilience, Recovery, Discipline, Intellect, and Strength.   | Useful within the same armor generation. Armor 3.0 ties total stats to gear tier; the sample had totals of 96 at Tier 4 and 100 at Tier 5. [Armor 3.0 update](https://www.bungie.net/7/en/News/Article/destiny_update_9_0_0_1).                                                                                                |
| Masterwork / Crafted                | Compact item-state flags for invested upgrades.                                 | Show as badges or use as tie-breakers. They do not describe a weapon's active perk choices. [Bungie item state](https://bungie-net.github.io/multi/schema_Destiny-ItemState.html).                                                                                                                                             |
| Enhanced traits                     | Count of enhanced active traits, derived from sockets and manifest definitions. | Store a count or boolean; discard socket plug hashes so random perk selections are not retained.                                                                                                                                                                                                                               |
| Armor energy capacity               | Available mod energy on compatible armor.                                       | Keep as an armor-specific upgrade signal. It is not comparable across all armor generations.                                                                                                                                                                                                                                   |
| Item objectives / catalyst progress | Per-item objectives when Bungie returns them.                                   | No objectives appeared in the 51-item live sample, so this is not a general signal for this profile. Use only when the objective is known and consistently available.                                                                                                                                                          |
| Set bonus                           | Benefits from wearing matching armor pieces.                                    | Evaluate at loadout level because the benefit depends on the equipped combination.                                                                                                                                                                                                                                             |

## Where to identify the indicators

Fetch `Destiny2/{membershipType}/Profile/{membershipId}` with the component numbers below. Join an inventory item's `itemInstanceId` to the per-item maps in `itemComponents`; join its `itemHash` and socket `plugHash` values to the manifest. The [Bungie component reference](https://bungie-net.github.io/multi/schema_Destiny-DestinyComponentType.html) defines these components, and the reusable script requests them explicitly.

| Component                                                        | Profile response path                                                                                               | Useful fields                                                                                                                                                                                                                   |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 102 ProfileInventories                                           | `profileInventory.data.items[]`                                                                                     | Vault items and their `itemHash`, `itemInstanceId`, `bucketHash`, and `state`.                                                                                                                                                  |
| 200 Characters, 201 CharacterInventories, 205 CharacterEquipment | `characters.data`, `characterInventories.data[characterId].items[]`, `characterEquipment.data[characterId].items[]` | Character records, carried items, equipped items, and each item's `state`. These arrays combine with component 102 for account-wide inventory.                                                                                  |
| 300 ItemInstances                                                | `itemComponents.instances.data[itemInstanceId]`                                                                     | `primaryStat.value`, `itemLevel`, `quality`, `gearTier`, and `energy.energyCapacity`. A gear tier of `0` appeared on 46 items in the sample; five items had tiers 4 or 5.                                                       |
| 304 ItemStats                                                    | `itemComponents.stats.data[itemInstanceId].stats[statHash].value`                                                   | Sum the six armor stat hashes: Mobility `2996146975`, Resilience `392767087`, Recovery `1943323491`, Discipline `1735777505`, Intellect `144602215`, Strength `4244567218`. This component appeared for 27 items in the sample. |
| 305 ItemSockets                                                  | `itemComponents.sockets.data[itemInstanceId].sockets[]`                                                             | Each active socket's `plugHash`; resolve it through `DestinyInventoryItemDefinition` to derive enhanced-trait counts, then discard the hashes. Two sample items had enhanced traits.                                            |
| 301 ItemObjectives                                               | `itemComponents.objectives.data[itemInstanceId].objectives[]`                                                       | `objectiveHash`, `progress`, `completionValue`, and `complete`; resolve `objectiveHash` through `DestinyObjectiveDefinition`. No item objectives were returned in the sample.                                                   |

The item definition manifest is at `jsonWorldComponentContentPaths.en.DestinyInventoryItemDefinition`; objective definitions are at `jsonWorldComponentContentPaths.en.DestinyObjectiveDefinition`. Item arrays carry `state` directly: bit `4` is Masterwork and bit `8` is Crafted, as defined by [Bungie's item-state enum](https://bungie-net.github.io/multi/schema_Destiny-ItemState.html). Armor energy is present only when the instance has an `energy` block. In this sample, 18 items had armor energy capacity and the state flags marked 15 Masterwork and one Crafted item.

The current script identifies enhanced traits by resolving each active socket plug through the item-definition manifest, then counting plugs in the Frames category (`plugCategoryHash` `7906839`) with tier type `3`. This follows the project's existing socket heuristic; it is a derived count, not a dedicated enhanced-trait flag in the profile response.

Set bonus is a combination-level signal. The profile components above do not expose a generic set-bonus progress field; identifying a set requires game-specific item/manifest metadata, then counting matching equipped pieces for the relevant thresholds. Do not infer a per-item set score from generic item-instance fields alone.

## Suggested comparison

Group items by slot and generation, then compare the tuple `(power, gear tier, armor stat total when relevant, Masterwork/enhanced flags)`. Keep perk synergy out of the score. Avoid collapsing unlike item types into one global number.

Live profile snapshot: 2026-11-03, manifest `245114.26.10.13.2000-1-bnet.66137`. The profile returned 51 unique items: 46 Tier 0, one Tier 4, and four Tier 5. It included one crafted item, 15 Masterwork items, two items with enhanced traits, and no item objectives. See the [detailed findings](destiny-item-progression.md) and [reusable inspector](../../scripts/inspect-destiny-items.mjs).
